# chatRecord

这里用于保存与“磕”二创项目无关、但值得沉淀的讨论结果。

## 使用范围

- 工具、插件、GitHub、Drive、资料管理等流程性结论。
- 与二创正文、世界观、人物分析无直接关系的长期操作规则。
- 需要日后复用的设置说明、故障排查记录和工作流约定。

## 不默认收录

- 个人健康、用药、家庭、工作、账号、财务、联系人、现实身份信息。
- 明确标记为私密、敏感、备忘、仅自己看的材料。
- 与“磕”项目创作资料边界冲突的内容。

如确需保存上述内容，必须由用户对具体文件或具体类别单独明示批准。

## 提交规则

- 一轮讨论敲定后，沉淀为一个 commit。
- 提交前先确认内容边界，不把二创静态资料混入本目录。
- 多文件变更应合并成同一轮提交；若工具只能单文件提交，先暂存方案，等可合并提交时再执行。
