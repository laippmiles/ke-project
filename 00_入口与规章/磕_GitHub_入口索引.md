## 默认读取顺序

1. 先读本入口索引。
2. 再读 `00_入口与规章/磕_项目指令_路标版.md`、`00_入口与规章/磕_资料维护规章.md` 和 `00_入口与规章/磕_项目规章_杀生丸与铃.md`。
3. 写小说正文、场景、对白、梗概、续写或最终润色前，默认读取 `01_核心总集/磕_谈话总集_02_二创世界观与长线创作圣经.md`。
4. 涉及杀生丸与铃的关系判断时，同时读取 `01_核心总集/磕_谈话总集_01_杀铃关系研究与人物理解.md`。
5. 涉及杀生丸对白时，同时读取 `02_原作对白与校准/10_主体对白集/杀生丸前期对白_杀邪铃互动_原作对白集.md` 和 `02_原作对白与校准/20_对白分析与台词校准/杀生丸前期对白_杀邪铃互动_对白分析与二创校准.md`。

如果无法访问指定 GitHub 文件，必须明确说明缺失，不能凭记忆补设定，也不能编造原作对白或项目规则。
